# UC-05 — T1558.004 Steal or Forge Kerberos Tickets: AS-REP Roasting

Status: PASS (with documented limitations)

## Hypothesis
An AS-REP roasting attempt (requesting a TGT for a no-pre-auth account without pre-authentication)
is detectable from Samba KDC log text.

## Detection logic
- Source: DC01 KDC lines arriving twice — `/var/log/samba/log.samba` (syslog) and journald. Decoder
  is empty (`{}`); only `full_log` + predecoder fields exist, so the rule matches on `full_log`.
- Rule `100034` (level 12, T1558.004): `<match>AS-REQ ERR_PREAUTH_REQUIRED</match>`.

## Trigger
From SOC01 (impacket 0.13.1):
```bash
GetNPUsers.py CORP/attacker:'Attacker!lab123' -dc-ip 10.10.10.10 -request -format hashcat
```
Targets the no-pre-auth account `victim` (UAC DONT_REQUIRE_PREAUTH).

## Expected vs observed
Expected: 100034 alert per AS-REQ-without-pre-auth.
Observed: `100034` fired many times (e.g. `2026-10-24T03:00:01` during the roast). Note Samba 4.19.5
returns `AS-REQ ERR_PREAUTH_REQUIRED` even for no-pre-auth accounts, so **no hash is actually
obtained** — detection is log-pattern-based, not evidence of a successful crack (see below).

## Benign control / False positives (KNOWN)
- **Duplicate alerts:** each AS-REQ line is ingested twice (log.samba + journald), so 100034 fires
  twice per line. Cosmetic — dedup (filter on `location`, or `same_field`/frequency) is future work.
- **Normal-Kerberos FP:** every Kerberos logon begins with an AS-REQ sent *without* pre-auth, so the
  KDC's `ERR_PREAUTH_REQUIRED` response occurs during normal operation too (observed for the domain-
  join computer account `desktop-i4qi720$@corp.lab`). The match is therefore noisy and not a strong
  stand-alone signal. Tightening (e.g. requiring the request to originate from a non-domain-joined
  source IP, or pairing with a follow-on absence of pre-auth success) is future work.

## Cleanup
Intentionally **not** cleaned up — lab kept attack-ready for study. `victim` keeps the no-pre-auth
flag (documented, harmless in the isolated lab).

## Troubleshooting notes
- AS-REP hash capture is not possible against Samba 4.19.5 (the KDC always requires pre-auth), so the
  exercise uses the `AS-REQ ERR_PREAUTH_REQUIRED` text pattern as the detection signal.

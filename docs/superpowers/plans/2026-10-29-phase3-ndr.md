# Phase 3 NDR — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up NDR01 (Suricata IDS on the `int-corp` segment), forward `eve.json` alerts to the existing Wazuh manager, and prove six real network detections plus the exit-gate marker.

**Architecture:** NDR01 runs Suricata in passive AF_PACKET IDS mode sniffing `int-corp`; its Wazuh agent tails `eve.json` (JSON decoder) and ships to SOC01. Seven Suricata rules (sids 7000001–7000007) map one-to-one to seven Wazuh rules (100040–100046) keyed on `alert.signature_id`. Power-on scenario S3 (SOC01 + WIN01 + NDR01); DC01 stays off.

**Tech Stack:** VirtualBox 7.2.x, Ubuntu Server 24.04 LTS, Suricata 8.0.x (Ubuntu PPA), Wazuh 4.14.8, impacket (on SOC01), nmap (Windows), pyftpdlib, plink/pscp, PowerShell 5.1.

**Spec:** `docs/superpowers/specs/2026-10-29-phase3-ndr-design.md`

## Global Constraints

- Power-on scenario **S3 only**: SOC01 (5 GB) + WIN01 (4 GB) + NDR01 (1 GB) = 10 GB. **DC01 stays powered OFF for the whole phase.** SOC01 is the attacker source for UC-11 (SMB); WIN01 is the attacker source for all other detections.
- User runs all attack simulations; assistant builds infrastructure and verifies (AGENTS.md rule).
- Custom **Wazuh** rules are edited ONLY via the dashboard UI by the user, then synced back to the repo and committed. No raw quote chars in UI regex text — use `\x22`/`\x27` (API error 1113). Suricata `local.rules` is infra config the assistant authors via SSH (not a Wazuh rule).
- SOC01/NDR01 stay offline after build (NAT detached). Package installs happen before detach. Temporary NAT is a documented exception only.
- Secrets never in git: passwords go only into `lab/runbook/.local-credentials.md` (gitignored). NDR01 local account `ndradmin/ndradmin123`; record it there.
- Every detection gets: case doc + exercise-log rows + lessons + evidence screenshot + commit (house lifecycle).
- Remote control: host → plink SOC01 (`10.10.30.10`) → `ssh ndradmin@10.10.10.40` for NDR01. Host cannot reach `int-corp` directly. `ssh` inside a piped remote script MUST use `< /dev/null` (stdin gotcha).
- Clock gotcha: after any NDR01 savestate/resume, check `date` first. Persist `clocksource=acpi_pm` on NDR01 via GRUB (same fix as DC01).
- Grep self-match gotcha: `sudo grep` on alerts.json emits a rule-5402 alert containing the grep command. Pipe `grep -v COMMAND` and grep the description phrase, not the rule id.
- Wazuh 4.14 rotates alerts/archives daily; yesterday's alerts are in rotated files, not live `alerts.json`. Use `zgrep` for older days.
